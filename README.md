# 🌟 Personal Dashboard

A modern web application that brings together essential daily widgets in one place, featuring a clean and intuitive Glassmorphism UI design.

## 🌐 Live Demo

https://ex-personal-dashboard.netlify.app

## ✨ Features

### 🌤️ Weather
- Display current weather conditions
- Search weather by city name
- Shows temperature, humidity, and wind speed

### 📅 Calendar
- Monthly calendar view
- Highlights the current day
- Navigate between months

### ✅ To-do List
- Add, delete, and edit tasks
- Filter by status (All / Active / Completed)
- Data persisted using LocalStorage

### 📝 Quick Notes
- Create short notes
- Edit and delete notes
- Displays creation timestamp

### 💬 Daily Quotes
- Fetch random quotes from API
- Refresh to get a new quote

### 🎨 Others
- 🌙 Dark/Light Mode
- 💾 Backup & Restore data (JSON)
- ⌨️ Keyboard Shortcuts
- 📱 Responsive Design

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: TailwindCSS + Glassmorphism
- **Icons**: Lucide React
- **HTTP Client**: Axios
- **State Management**: React Hooks + LocalStorage
- **APIs**: OpenWeatherMap API, Quotable API

## 🚀 Quick Start


### Installation & Run

```bash
# Clone the repository
git clone https://github.com/WoranutKhwanpongdee/Personal-dashboard
cd personal-dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```
